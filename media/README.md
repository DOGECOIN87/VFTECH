# Media

`VFTech-landing-4K.mp4` is a 4K desktop recording of the landing page: 3840×2160 (a 1920×1080 layout at 2×), 30 fps, 38 s, H.264. It runs in three parts:

1. The hero intro: rays of light run along the hero's borders and meet at the mark, the type rises in reading order, then the chrome mark draws, extrudes and makes one full turn under its key light.
2. The page scrolls through every section.
3. The recording holds on the drifting monogram footer.

It was captured frame by frame on a virtual clock, so every animation plays at true speed with no dropped frames. It is kept outside `site/`, so it isn't published with the website.
