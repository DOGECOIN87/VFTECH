# Pulse / design 9

A project board with three equal columns and a perfect-fifth type rhythm. Bricolage Grotesque supplies the expressive headings; Figtree handles compact task text. Both fonts are self-hosted with OFL licenses. The new vector logo and existing motion choreography appear on all seven pages.

Eight fictional Harbor Supply tasks demonstrate the delivery workflow. Search, owner filters, board/list tabs and completion progress respond to the current sample tasks. Keyboard-accessible dialogs add or edit task names, notes, owner and stage. Nothing is sent to a server, and changes last until the page refreshes.

The three-column desktop board stacks naturally on phones. Tasks are moved with a labelled stage selector rather than requiring drag and drop. Escape closes the dialog and focus returns to the task or add control. Tabs support arrow keys, Home and End.

Existing service content is retained, with rounded project panels and the same purple/lime palette. Continuous canvas and WebGL effects are removed from this homepage.
