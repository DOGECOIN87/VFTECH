# Mono / design 10

A knowledge base rather than a marketing hero. A guide library and on-page contents rail frame a readable serif article. The reading design uses a 2:3 margin rhythm (22/33 callout inset and 32/48 larger spacing) and two-to-three ownership rows. It opens in light mode for a new visitor and respects a saved dark preference.

Newsreader handles the article and headings, Schibsted Grotesk handles navigation, and Fragment Mono handles quiet reference text. All fonts are self-hosted with OFL licenses. All seven pages use the new vector logo and the existing motion choreography.

Search filters a local index of guides and article sections, with working links to the existing pages. The slash and Ctrl/Cmd-K shortcuts open search; arrow keys browse results and Escape closes it. On-page links track the current reading section. The guide library and contents use native disclosure controls on phones.

The six existing service pages retain their content and interactive tools, with the same restrained reading typography. No server search, live data, continuous canvas or WebGL scene is added.
