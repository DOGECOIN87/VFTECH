# Console / design 8

A service monitoring interface with an operational chart, service inventory and event stream. The chart and status rail use a square-root-of-two split. Condensed headings and timestamped mono details make this direction distinct from the Ledger dashboard.

Self-hosted Barlow Semi Condensed and JetBrains Mono include their OFL licenses. All seven pages use the new vector logo and existing motion choreography, with reduced motion supported.

The homepage is a labelled sample environment. Environment selection, time ranges and metric selection change local chart fixtures. A readings table provides a text equivalent of the chart. Refreshing advances a local sample snapshot; it makes no network requests. Service buttons show details. Event severity filters and CSV export operate on the visible sample events.

The service pages retain their original content and tools, with the Console typography, sharp panels and green accent. No continuous animation or WebGL scene runs on this homepage.
