# Design 5 — Orbit

A new homepage composition with graphite surfaces, blue accents, chrome VF animation, asymmetric service cards, and an ownership-led story. Light and dark themes are supported.

The original VF logo contours and chrome renderer are preserved. All six supporting pages share Orbit styling and keep the existing content and contact request composer. The form still composes a request for copying; it does not send one.

Published at `/VFTECH/design-5/`. The five-way design switcher preserves the current page. GitHub Pages assembles all options on pushes to main.

The local TT Norms Pro Mono font is reused from the repository. No remote fonts, images, or model requests are needed.
